# 5.4  Windows Remote Management (WinRM)
*Part 5: Remote Access and Lateral Movement*

## Analyze hunts

WinRM tooling by name:

```
filename:[*winrm*,evil-winrm*,*pywinrm*,*wsman*] classification:[malicious, suspicious]
```

Binaries that call the WS-Management API:

```
pe-function:[WSManCreateSession*,WSManRunShellCommand*,WSManConnectShell*,WSManInitialize] classification:[malicious, suspicious]
pe-import:wsmsvc.dll classification:[malicious, suspicious]
```

Embedded WinRM endpoints:

```
uri:["*:5985*","*:5986*","*/wsman*"] classification:[malicious, suspicious]
```

PowerShell remoting scripts:

```
threatname:Script-PowerShell.* av-detection:*remot*
```

ATT&CK mapping for remote services:

```
attack-technique:T1021
```

## evil-winrm-py

The tool by name:

```
filename:[*evil-winrm*,evil_winrm*] classification:[malicious, suspicious, unknown]
```

It is a Python package, so look for the scripts and for compiled copies:

```
threatname:Script-Python.* filename:*winrm*
```

The embedded PowerShell script (send.ps1):

```
filename:send.ps1 classification:[malicious, suspicious, unknown]
```

WinRM-related tooling in general:

```
filename:[*winrm*,*wsman*,*pywinrm*] classification:[malicious, suspicious]
```
