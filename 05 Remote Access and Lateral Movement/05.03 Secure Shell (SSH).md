# 5.3  Secure Shell (SSH)
*Part 5: Remote Access and Lateral Movement*

## Hunts

SSH client and server binaries:

```
filename:[putty*,plink*,pscp*,psftp*,openssh*,sshd,ssh.exe,dropbear*] classification:[malicious, suspicious]
```

Windows executables whose product name identifies them as PuTTY:

```
pe-product-name:*putty* classification:[malicious, suspicious]
```

Files that embed SSH URIs or port 22 and 2222 targets:

```
uri:[ssh*,"*:22","*:2222"] classification:[malicious, suspicious]
```

ELF samples that use SSH-related symbols:

```
elf-symbol:[*ssh*,*libssh*] classification:[malicious, suspicious]
```

Files exploiting known OpenSSH vulnerabilities, such as regreSSHion:

```
exploit:cve-2024-6387
```
