# 5.1  Server Message Block (SMB) and PsExec
*Part 5: Remote Access and Lateral Movement*

## Server Message Block (SMB)

### PsExec and remote-service tooling

This replaces the `psexecsvc`, `PSEXESVC.EXE` and `svcctl` payload matches:

```
filename:[psexec*,psexesvc*,paexec*,remcom*] classification:[malicious, suspicious]
pe-original-name:[PSEXESVC.exe,psexec.exe] classification:[malicious, suspicious]
```

Samples that reference `ADMIN$` or `IPC$` shares:

```
uri-static:[*ADMIN$*,*IPC$*,*C$*] classification:[malicious, suspicious]
```

### SMB API usage

Binaries that enumerate or connect to shares:

```
pe-function:[NetShareEnum*,NetSessionEnum*,WNetAddConnection2*,NetUseAdd*] classification:[malicious, suspicious]
pe-import:[mpr.dll,netapi32.dll] classification:malicious
```

### Services started over SMB (svcctl)

```
pe-function:[OpenSCManager*,CreateService*,StartService*] classification:malicious
```

### Known SMB exploits (EternalBlue, EternalRomance and Petya-family)

```
exploit:[CVE-2017-0143, CVE-2017-0144, CVE-2017-0145, CVE-2017-0146, CVE-2017-0147, CVE-2017-0148]
threatname:*.Ransomware.*Petya*
```

### ATT&CK mapping for SMB techniques

```
attack-technique:[T1021, T1039, T1570]
```

### Sensitive hosts, accounts and file names (old "Hunt For" list)

Pivot on file names directly:

```
filename:[*.exe,*.dll,*.bat] attack-technique:T1570 classification:[malicious, suspicious]
```

## PsExec service execution

PsExec and its look-alikes as files:

```
filename:[psexec*,psexesvc*,paexec*,remcom*] classification:[malicious, suspicious, unknown]
```

Renamed copies:

```
pe-original-name:[PSEXESVC.exe,psexec.exe] NOT filename:[psexec*,psexesvc*]
```

Samples that map to the techniques:

```
attack-technique:[T1543, T1021, T1569]
```

Samples that reference the admin shares PsExec uses:

```
uri-static:[*ADMIN$*,*IPC$*] classification:[malicious, suspicious]
```
