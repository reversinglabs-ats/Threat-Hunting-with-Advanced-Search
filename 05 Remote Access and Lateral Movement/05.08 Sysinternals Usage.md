# 5.8  Sysinternals Usage
*Part 5: Remote Access and Lateral Movement*

## Hunts

On company and product name:

```
pe-company-name:*Sysinternals* OR pe-product-name:*Sysinternals*
```

Only the ones that are not known-good:

```
pe-company-name:*Sysinternals* classification:[malicious, suspicious, unknown]
```

The commonly abused ones by name:

```
filename:[psexec*,procdump*,adexplorer*,adrestore*,accesschk*,psexesvc*,sdelete*,pskill*,psloggedon*]
```

Renamed copies:

```
pe-company-name:*Sysinternals* NOT filename:[psexec*,procdump*,adexplorer*,accesschk*,sdelete*]
```
