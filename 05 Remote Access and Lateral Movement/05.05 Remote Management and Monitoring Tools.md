# 5.5  Remote Management and Monitoring Tools
*Part 5: Remote Access and Lateral Movement*

## Remote Management Monitoring Tools

By file name:

```
filename:[ScreenConnect.Client.exe,ScreenConnect.Service.exe,AgentMon.exe,ccme_sm.exe,GetASRSettings.exe,kworking.exe,klnagent.exe,NinjaRMM.exe,NinjaRMMAgent.exe,AteraAgent.exe,AteraRC.exe,PulsewayService.exe,Pulseway.TrayApp.exe,Auvik.Engine.exe,Auvik.Agent.exe,Domotz.exe,DomotzClient.exe,LTClient.exe,LTAService.exe,VncClient.exe,NAPClt.exe,TakeControlRDViewer.exe,ZA_Connect.exe,LTSvcMon.exe,teamviwer.exe,putty.exe,winvnc.exe,LogMeIn.exe]
```

Same tools, matched on the compile-time name rather than the on-disk name. This catches renamed binaries:

```
pe-original-name:[ScreenConnect.Client.exe,NinjaRMMAgent.exe,AteraAgent.exe,PulsewayService.exe,LogMeIn.exe,winvnc.exe,putty.exe]
```

By publisher:

```
pe-company-name:[*ConnectWise*,*NinjaRMM*,*Atera*,*Pulseway*,*LogMeIn*,*TeamViewer*,*Kaseya*]
```

Only the ones that are not clean:

```
filename:[ScreenConnect.Client.exe,AteraAgent.exe,NinjaRMMAgent.exe,LogMeIn.exe] classification:[malicious, suspicious, unknown]
```

Renamed RMM tooling, with the on-disk name not matching the compile-time name:

```
pe-original-name:[ScreenConnect.Client.exe,AteraAgent.exe,NinjaRMMAgent.exe] NOT filename:[ScreenConnect.Client.exe,AteraAgent.exe,NinjaRMMAgent.exe]
```

## TeamViewer

### Analyze hunts

TeamViewer binaries by name, including the misspelling used in the RMM list:

```
filename:[*teamviewer*,teamviwer.exe,TeamViewer_Service.exe,tv_w32.exe,tv_x64.exe]
```

By publisher:

```
pe-company-name:"TeamViewer*"
```

Only the ones that are not known-good, which often means a trojanized or renamed copy:

```
pe-company-name:"TeamViewer*" classification:[malicious, suspicious, unknown]
```

Renamed TeamViewer, where the compile-time name is `TeamViewer` but the file name is not:

```
pe-original-name:*teamviewer* NOT filename:*teamviewer*
```

Samples that embed TeamViewer's primary port:

```
uri:"*:5938*"
```

Application identification:

```
appid-product-name:TeamViewer
```
