# 5.9  Network Scanners
*Part 5: Remote Access and Lateral Movement*

## SoftPerfect Network Scanner

By file name:

```
filename:netscan*
```

By publisher and product:

```
pe-company-name:*SoftPerfect* OR pe-product-name:*Network Scanner*
```

Renamed copies:

```
pe-company-name:*SoftPerfect* NOT filename:netscan*
```

Not clean:

```
pe-company-name:*SoftPerfect* classification:[malicious, suspicious, unknown]
```

ATT&CK mapping:

```
attack-technique:T1046
```

## Advanced IP Scanner and Advanced Port Scanner

By file name:

```
filename:[advanced_ip_scanner*,advanced_port_scanner*]
```

By publisher and product:

```
pe-company-name:*Famatech* OR pe-product-name:[*Advanced IP Scanner*,*Advanced Port Scanner*]
```

Renamed copies:

```
pe-company-name:*Famatech* NOT filename:[advanced_ip_scanner*,advanced_port_scanner*]
```

Not clean:

```
pe-company-name:*Famatech* classification:[malicious, suspicious, unknown]
```
