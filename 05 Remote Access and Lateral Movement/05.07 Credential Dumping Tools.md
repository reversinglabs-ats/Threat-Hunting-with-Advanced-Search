# 5.7  Credential Dumping Tools
*Part 5: Remote Access and Lateral Movement*

## Hunts

The tooling by name:

```
filename:[*secretsdump*,*crackmapexec*,*netexec*,nxc*,*impacket*,*cme.exe] classification:[malicious, suspicious]
```

Compiled Python tools (these embed an interpreter):

```
pe-function:"Py_Initialize" filename:[*secretsdump*,*crackmapexec*,*netexec*,nxc*] classification:[malicious, suspicious]
```

Python scripts:

```
threatname:Script-Python.* classification:[malicious, suspicious]
```

Samples that map to the technique:

```
attack-technique:[T1003, T1021]
```
