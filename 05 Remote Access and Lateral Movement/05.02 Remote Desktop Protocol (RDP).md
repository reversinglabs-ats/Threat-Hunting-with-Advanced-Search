# 5.2  Remote Desktop Protocol (RDP)
*Part 5: Remote Access and Lateral Movement*

## Hunts

RDP clients, servers and tooling by name:

```
filename:[mstsc*,xfreerdp*,rdesktop*,xrdp*,*rdpwrap*,*mimikatz*] classification:[malicious, suspicious]
```

Version-info fields that name Remote Desktop:

```
pe-product-name:"*remote desktop*" classification:[malicious, suspicious]
pe-original-name:[mstsc.exe,rdpclip.exe] classification:[malicious, suspicious]
```

Binaries that import terminal-services APIs:

```
pe-import:wtsapi32.dll classification:[malicious, suspicious]
pe-function:[WTSEnumerateSessions*,WTSQuerySessionInformation*,WTSVirtualChannelOpen*]
```

Samples that embed RDP endpoints:

```
uri:"*:3389*" classification:[malicious, suspicious]
```

Samples that exploit known RDP flaws, for example BlueKeep:

```
exploit:[CVE-2019-0708, CVE-2019-1181, CVE-2019-1182]
```

ATT&CK mapping for RDP lateral movement and session hijack:

```
attack-technique:[T1021, T1563]
```

## RDPWrap

RDPWrap and its installer files:

```
filename:[*rdpwrap*,rdpwinst*,rdpconf*,rdpcheck*] classification:[malicious, suspicious, unknown]
```

By version info:

```
pe-product-name:*RDP*Wrapper* OR pe-description:*RDP*Wrapper*
```

Samples that reference the TermService parameters:

```
uri-static:[*TermService*,*AllowMultipleTSSessions*,*Licensing Core*] classification:[malicious, suspicious]
```

ATT&CK mapping:

```
attack-technique:[T1505, T1021]
```
