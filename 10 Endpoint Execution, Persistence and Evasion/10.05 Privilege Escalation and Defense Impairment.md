# 10.5  Privilege Escalation and Defense Impairment
*Part 10: Endpoint Execution, Persistence and Evasion*

## Access token manipulation

Samples mapped to the technique:

```
attack-technique:T1134
```

Binaries that use the token APIs:

```
pe-function:[OpenProcessToken,DuplicateToken*,ImpersonateLoggedOnUser,SetThreadToken,AdjustTokenPrivileges,CreateProcessWithTokenW,CreateProcessAsUser*] classification:[malicious, suspicious]
```

Privilege lookups that go with it:

```
pe-function:[LookupPrivilegeValue*,NtSetInformationToken,NtAdjustPrivilegesToken] classification:[malicious, suspicious]
```

Impersonation and potato-style privilege escalation tools by name:

```
filename:[*incognito*,*potato*,*printspoofer*,*roguepotato*,*sweetpotato*,*godpotato*,*tokenvator*,*mimikatz*] classification:[malicious, suspicious]
```

Compile-time names, to catch renamed copies:

```
pe-original-name:[PrintSpoofer.exe,JuicyPotato.exe,RoguePotato.exe,SweetPotato.exe,GodPotato.exe,mimikatz.exe] NOT filename:[*printspoofer*,*juicypotato*,*roguepotato*,*sweetpotato*,*godpotato*,*mimikatz*]
```

Dangerous privilege names appearing as strings in a sample:

```
uri-static:[*SeDebugPrivilege*,*SeImpersonatePrivilege*,*SeTcbPrivilege*,*SeAssignPrimaryTokenPrivilege*] classification:[malicious, suspicious]
```

The privilege strings are more likely to be found in scripts and .NET assemblies than in indexed URIs, so treat a miss as inconclusive.

```
dotnet-pinvoke-function:[OpenProcessToken,DuplicateTokenEx,ImpersonateLoggedOnUser,AdjustTokenPrivileges,CreateProcessWithTokenW] classification:[malicious, suspicious]
```

## powercfg

Samples mapped to the techniques:

```
attack-technique:[T1562, T1070]
```

Scripts and binaries that reference the tool:

```
uri-static:*powercfg* classification:[malicious, suspicious]
filename:*powercfg* classification:[malicious, suspicious]
```

Scripts that are flagged as defense-evasion or impact tooling:

```
attack-tactic:TA0005 threatname:[Script-BAT.*,Script-PowerShell.*] classification:[malicious, suspicious]
```

Tampered copies of the tool itself (compile-time name `powercfg.exe` with a different file name):

```
pe-original-name:powercfg.exe NOT filename:powercfg.exe
```

## Vulnerable and malicious drivers (LOLDRIVERS)

Drivers as files that are not clean:

```
filename:*.sys classification:[malicious, suspicious]
```

A batch of hashes from the LOLDRIVERS list. A query holds roughly 24 SHA1 values within 1024 characters:

```
hashes:[<sha1_1>, <sha1_2>, <sha1_3>]
```

Well-known vulnerable drivers by name (confirm against the current list):

```
filename:[RTCore64.sys,gdrv.sys,DBUtil_2_3.sys,mhyprot2.sys,aswArPot.sys,iqvw64e.sys,AsIO3.sys,zamguard64.sys]
```

Renamed copies, matched on the compile-time name:

```
pe-original-name:[RTCore64.sys,gdrv.sys,DBUtil_2_3.sys,mhyprot2.sys] NOT filename:[RTCore64.sys,gdrv.sys,DBUtil_2_3.sys,mhyprot2.sys]
```

Samples that map to exploitation for privilege escalation:

```
attack-technique:T1068
```
