# 10.1  Initial Access Delivery
*Part 10: Endpoint Execution, Persistence and Evasion*

## Hunts

### Disk images and containers

```
threatname:[Archive-ISO.*,Archive-ZIP.*,Archive-RAR.*,Archive-7ZIP.*,Archive-CAB.*] classification:[malicious, suspicious]
filename:[*.iso,*.img,*.vhd,*.vhdx,*.cab] classification:[malicious, suspicious]
```

Archives that unpack to many files (local appliance only):

```
filecount:[20 TO *] classification:[malicious, suspicious] filename:[*.zip,*.rar,*.7z,*.iso]
```

### Shortcuts

```
threatname:Shortcut.*
filename:*.lnk classification:[malicious, suspicious]
```

### Help files, HTML applications, OneNote

```
threatname:[Document-CHM.*,Document-HTML.*,Script-JS.*] classification:[malicious, suspicious]
filename:[*.chm,*.hta,*.html,*.htm,*.one,*.js,*.jse,*.vbs,*.wsf] classification:[malicious, suspicious]
```

### Office documents with macros

```
threatname:[Document-Word.*,Document-Excel.*,Document-PowerPoint.*,Document-Office.*] classification:[malicious, suspicious]
type:Document/* av-detection:*macro* classification:[malicious, suspicious]
```

Documents that exploit a CVE:

```
type:Document/* exploit:[cve-2017-11882, cve-2017-0199, cve-2022-30190]
```

### Documents from email

```
upload-source:smtp type:Document/* classification:[malicious, suspicious]
```

### ATT&CK mapping

```
attack-technique:[T1566, T1204]
```

## Spearphishing attachments

### The attachment (spearphishing delivery)

Office and PDF threats by detection name:

```
threatname:[Document-Word.*,Document-Excel.*,Document-PowerPoint.*,Document-Office.*,Document-PDF.*] classification:[malicious, suspicious]
```

Attachments by sender or subject:

```
email-from:*@<suspect-domain> classification:[malicious, suspicious]
```

Other attachment types that start execution (HTA, JS, shortcuts, ISO):

```
filename:[*.hta,*.js,*.vbs,*.lnk,*.iso,*.chm] classification:[malicious, suspicious]
```

### The LOLBin and downloader indicators

Scripts and documents that fetch a payload:

```
uri-static:* classification:malicious type:Document/*
uri-dynamic:* type:Document/* classification:[malicious, suspicious]
```

The LOLBins as files, when they are not the genuine one (renamed or tampered copies). The compile-time name stays `certutil.exe` while the file name differs:

```
pe-original-name:[certutil.exe,mshta.exe,regsvr32.exe,rundll32.exe,bitsadmin.exe,wmic.exe,expand.exe] NOT filename:[certutil.exe,mshta.exe,regsvr32.exe,rundll32.exe,bitsadmin.exe,wmic.exe,expand.exe]
```

### ATT&CK mapping

```
attack-technique:[T1566, T1204, T1059, T1105]
```

## LNK files

By detection name:

```
threatname:Shortcut.* classification:[malicious, suspicious]
```

Shortcuts with a double extension (a document name that is really a shortcut):

```
filename:[*.pdf.lnk,*.doc.lnk,*.docx.lnk,*.xls.lnk,*.xlsx.lnk,*.jpg.lnk,*.txt.lnk] classification:[malicious, suspicious]
```

Shortcuts that arrived by email or inside a container:

```
filename:*.lnk upload-source:smtp classification:[malicious, suspicious]
filename:*.lnk threatname:[Archive-ISO.*,Archive-ZIP.*,Archive-RAR.*,Archive-7ZIP.*]
```

Recently seen, unclassified shortcuts (triage):

```
filename:*.lnk classification:unknown firstseen:3d-
```

Small files, since a shortcut that only launches a command is tiny:

```
filename:*.lnk size:10KB- classification:[suspicious, unknown, malicious]
```

Indicators the shortcut carries (a download URL in its arguments):

```
uri-static:* filename:*.lnk classification:[malicious, suspicious]
uri-dynamic:* filename:*.lnk classification:[malicious, suspicious]
```

Script engines as files that are not genuine:

```
pe-original-name:[mshta.exe,wscript.exe,cscript.exe,regsvr32.exe,rundll32.exe] NOT filename:[mshta.exe,wscript.exe,cscript.exe,regsvr32.exe,rundll32.exe]
```

ATT&CK mapping:

```
attack-technique:[T1204, T1564]
```

## Virtual drives inside archives

Disk images that are not clean:

```
filename:[*.iso,*.img,*.vhd,*.vhdx,*.wim] classification:[malicious, suspicious]
```

By detection name (the naming standard has an `Archive-ISO` platform):

```
threatname:Archive-ISO.*
```

Containers that arrived by email:

```
filename:[*.iso,*.img,*.vhd,*.vhdx,*.wim] upload-source:smtp classification:[malicious, suspicious]
```

Archives that wrap a disk image (local appliance, counts unpacked files):

```
filename:[*.zip,*.rar,*.7z] filecount:[1 TO 5] classification:[malicious, suspicious]
```

Exploits CVE-2023-36884 and CVE-2023-36584:

```
exploit:[cve-2023-36884, cve-2023-36584]
```
