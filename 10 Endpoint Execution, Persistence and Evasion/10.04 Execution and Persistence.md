# 10.4  Execution and Persistence
*Part 10: Endpoint Execution, Persistence and Evasion*

## DLL side-loading

### Renamed DLL (file name differs from compile-time name)

A generic form. Replace the name with a DLL you want to watch:

```
pe-original-name:version.dll NOT filename:version.dll type:PE/*
```

Common side-loading targets, in one query:

```
pe-original-name:[version.dll,wtsapi32.dll,dbghelp.dll,winmm.dll,cryptsp.dll,msimg32.dll,dwmapi.dll,userenv.dll,uxtheme.dll,iphlpapi.dll] NOT filename:[version.dll,wtsapi32.dll,dbghelp.dll,winmm.dll,cryptsp.dll,msimg32.dll,dwmapi.dll,userenv.dll,uxtheme.dll,iphlpapi.dll]
```

Same test restricted to samples with a verdict:

```
pe-original-name:[version.dll,winmm.dll,dbghelp.dll] NOT filename:[version.dll,winmm.dll,dbghelp.dll] classification:[malicious, suspicious]
```

### Proxy DLLs (exports that forward to the real library)

```
pe-export:[GetFileVersionInfo*,VerQueryValue*] type:PE/* classification:[malicious, suspicious, unknown]
```

### Side-loaded DLLs from signed software

Unsigned or unknown DLLs from a vendor that normally signs everything. First find the signed host application by publisher, then look for DLLs that carry its original name:

```
pe-company-name:"<Vendor>" pe-original-name:*.dll NOT cert-subject-org:"<Vendor>"
```

### By detection name

```
threatname:[Win32.Trojan.*,Win64.Trojan.*] pe-original-name:*.dll NOT filename:*.dll
```

### ATT&CK mapping

```
attack-technique:[T1574, T1036]
```

## Python execution

By file name:

```
filename:[*.py,*.pyw,*.pyc,*.pyz] classification:[malicious, suspicious]
```

Executables that embed a Python interpreter. The docs use `pe-function:"Py_Initialize"` as their example for an exact function match:

```
pe-function:[Py_Initialize,Py_Main,PyRun_SimpleString,PyImport_ImportModule] classification:[malicious, suspicious]
```

Python runtime DLLs:

```
pe-import:[python3*.dll,python2*.dll] classification:[malicious, suspicious]
```

Compile-time and publisher names:

```
pe-original-name:[python.exe,pythonw.exe,py.exe] NOT filename:[python*.exe,pythonw.exe,py.exe]
pe-company-name:"Python Software Foundation" classification:[malicious, suspicious]
```

Python malware that opens sockets or loads payloads (indicator side):

```
threatname:Script-Python.* uri-static:* classification:malicious
threatname:Script-Python.* uri-config:*
```

ATT&CK mapping:

```
attack-technique:T1059
```

## NSSM

By file name:

```
filename:nssm*
```

By compile-time name and product:

```
pe-original-name:nssm.exe OR pe-product-name:*nssm*
```

Not clean:

```
filename:nssm* classification:[malicious, suspicious, unknown]
```

Coinminers, which are often kept running with NSSM:

```
threatname:*.Coinminer.*
```

ATT&CK mapping:

```
attack-technique:[T1569, T1543]
```

## PowerShell profiles

Profile scripts that are not clean:

```
filename:[Profile.ps1,Microsoft.PowerShell_profile.ps1] classification:[malicious, suspicious]
```

Profile files with no verdict yet (triage):

```
filename:[Profile.ps1,Microsoft.PowerShell_profile.ps1] classification:unknown
```

Same, by detection name:

```
threatname:Script-PowerShell.* filename:[Profile.ps1,Microsoft.PowerShell_profile.ps1]
```

Other PowerShell profile names (all-hosts and ISE profiles):

```
filename:[profile.ps1,microsoft.powershell_profile.ps1,microsoft.powershellise_profile.ps1,microsoft.vscode_profile.ps1]
```

Profile scripts that carry an indicator:

```
filename:[Profile.ps1,Microsoft.PowerShell_profile.ps1] uri-static:* classification:[malicious, suspicious]
```

ATT&CK mapping:

```
attack-technique:T1546
```
