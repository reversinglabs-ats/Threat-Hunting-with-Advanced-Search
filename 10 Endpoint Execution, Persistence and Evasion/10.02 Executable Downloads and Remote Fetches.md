# 10.2  Executable Downloads and Remote Fetches
*Part 10: Endpoint Execution, Persistence and Evasion*

## Executables and scripts fetched over the network

URLs that point at executables and scripts, in samples that are not clean:

```
uri:[*.exe,*.msi,*.dll,*.ps1,*.cmd,*.bat,*.sys] classification:[malicious, suspicious]
```

As static analysis, dynamic analysis or config indicators:

```
uri-static:[*.exe,*.dll,*.ps1,*.bat] classification:malicious
uri-dynamic:[*.exe,*.dll,*.ps1,*.bat] classification:[malicious, suspicious]
```

Where a file was downloaded from. `uri-source` (alias `itw`) is the origin URL:

```
itw:[*.exe,*.msi,*.dll,*.ps1,*.cmd,*.bat,*.sys] classification:[malicious, suspicious]
```

ATT&CK mapping:

```
attack-technique:T1105
```

## Downloads from uncommon TLDs

Files downloaded from risky TLDs, using the origin URL (uri-source, alias itw):

```
itw:[*.ru/*,*.su/*,*.cn/*,*.tk/*,*.top/*,*.xyz/*,*.biz/*,*.info/*,*.buzz/*,*.cf/*,*.ga/*,*.gq/*,*.ml/*,*.pw/*,*.cc/*] classification:[malicious, suspicious]
```

Same, restricted to executable, script and archive extensions:

```
itw:[*.ru/*,*.su/*,*.cn/*,*.tk/*,*.top/*,*.xyz/*,*.biz/*,*.info/*] filename:[*.exe,*.dll,*.ps1,*.cmd,*.bat,*.zip] classification:[malicious, suspicious, unknown]
```

Everything outside the common TLDs (.com, .net, .org, .ca). This is a wide query, so keep a verdict filter:

```
uri-source:* NOT itw:[*.com/*,*.net/*,*.org/*,*.ca/*] classification:[malicious, suspicious]
```

## WebDAV fetches

Samples that carry WebDAV paths to executables and scripts:

```
uri:[*DavWWWRoot*,*@SSL*,*/webdav/*] classification:[malicious, suspicious]
```

WebDAV paths ending in executable and script extensions:

```
uri:[*webdav*.exe,*webdav*.dll,*webdav*.bat,*webdav*.cmd,*webdav*.ps1,*webdav*.lnk,*webdav*.vbs,*webdav*.js,*webdav*.hta,*webdav*.wsf] classification:[malicious, suspicious]
```

As config, static and sandbox indicators:

```
uri-dynamic:[*DavWWWRoot*,*@SSL*,*webdav*] classification:[malicious, suspicious]
```

The `search-ms:` and shortcut delivery the sources describe:

```
threatname:Shortcut.* uri:*DavWWWRoot*
```

Where a file was fetched from:

```
itw:[*webdav*] classification:[malicious, suspicious]
```

The campaigns by name. These are family-name guesses:

```
threatname:[*Emmenhtal*,*Strela*,*Voldemort*]
```
