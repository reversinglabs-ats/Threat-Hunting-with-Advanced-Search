# 10.3  Masquerading and Binary Evasion
*Part 10: Endpoint Execution, Persistence and Evasion*

## Double extensions

Double-extension shortcuts:

```
filename:[*.doc.lnk,*.docx.lnk,*.xls.lnk,*.xlsx.lnk,*.ppt.lnk,*.pptx.lnk,*.pdf.lnk,*.zip.lnk,*.rar.lnk,*.7z.lnk,*.rtf.lnk]
```

Same, restricted to files with a verdict:

```
filename:[*.doc.lnk,*.docx.lnk,*.xls.lnk,*.xlsx.lnk,*.pdf.lnk,*.zip.lnk,*.rtf.lnk] classification:[malicious, suspicious]
```

Double extensions on executables, the other common form:

```
filename:[*.pdf.exe,*.doc.exe,*.docx.exe,*.xls.exe,*.xlsx.exe,*.zip.exe,*.rar.exe,*.jpg.exe,*.pdf.scr] classification:[malicious, suspicious]
```

Families by name (family-name guesses, because the naming standard leaves the family free text):

```
threatname:[*DarkGate*,*Lumma*,*Amadey*,*HijackLoader*]
```

ATT&CK mapping:

```
attack-technique:T1036
```

## Renamed binaries

Rclone: the compile-time name stays rclone.exe while the file name differs:

```
pe-original-name:rclone.exe NOT filename:rclone*
```

7-Zip and WinRAR:

```
pe-original-name:[7z.exe,7za.exe,7zr.exe,winrar.exe,rar.exe] NOT filename:[7z*,winrar*,rar*]
```

Transfer and tunnel tools whose compile-time name differs from the file name:

```
pe-original-name:[rclone.exe,winscp.exe,azcopy.exe,plink.exe,ngrok.exe,nssm.exe,psexec.exe] NOT filename:[rclone*,winscp*,azcopy*,plink*,ngrok*,nssm*,psexec*]
```

Renamed system utilities:

```
pe-original-name:[certutil.exe,mshta.exe,regsvr32.exe,rundll32.exe,bitsadmin.exe] NOT filename:[certutil.exe,mshta.exe,regsvr32.exe,rundll32.exe,bitsadmin.exe]
```

Add a verdict filter to cut noise:

```
pe-original-name:rclone.exe NOT filename:rclone* classification:[malicious, suspicious, unknown]
```

## Short numeric file names

One to three characters, in executable and script extensions. ? matches exactly one character and also letters, so this is broader than digits only:

```
filename:[?.exe,??.exe,???.exe,?.dll,??.dll,???.dll,?.ps1,??.ps1,???.ps1,?.bat,??.bat,???.bat,?.cmd,??.cmd,???.cmd,?.msi,??.msi,???.msi]
```

Restricted to files with a verdict, which removes most of the false positives:

```
filename:[?.exe,??.exe,???.exe,?.dll,??.dll,???.dll,?.ps1,??.ps1,???.ps1,?.bat,??.bat,???.bat] classification:[malicious, suspicious]
```

Recently seen, unclassified (the triage view):

```
filename:[?.exe,??.exe,???.exe,?.ps1,??.ps1,???.ps1,?.bat,??.bat,???.bat] classification:unknown firstseen:3d-
```

## PortableApps

The `.paf.exe` naming:

```
filename:*.paf.exe
```

Downloaded from the source site. uri-source (alias itw) is the origin URL of a file:

```
itw:*portableapps.com*
```

Not clean:

```
filename:*.paf.exe classification:[malicious, suspicious, unknown]
```

Portable browsers:

```
filename:[*chromeportable*,*firefoxportable*,*operaportable*]
```

## Oversized EXE and MSI files

The size threshold. 300000000 bytes is 300 MB in decimal units:

```
size:300MB+ filename:[*.exe,*.msi]
```

Same, only files that are not clean:

```
size:300MB+ filename:[*.exe,*.msi] classification:[malicious, suspicious, unknown]
```

A size band:

```
size:[300MB TO 1GB] filename:[*.exe,*.msi]
```

Bloated PE files, by type:

```
size:100MB+ type:PE/* classification:[malicious, suspicious]
```
