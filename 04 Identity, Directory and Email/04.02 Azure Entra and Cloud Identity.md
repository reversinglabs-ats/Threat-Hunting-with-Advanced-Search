### Cloud-identity attack tooling

Tools used to abuse tokens and app secrets in Entra ID and Azure:

```
filename:[*roadtools*,*roadrecon*,*aadinternals*,*tokentactics*,*azurehound*,*msolspray*,*graphrunner*] classification:[malicious, suspicious]
```

PowerShell scripts that carry such tooling:

```
threatname:Script-PowerShell.* filename:[*aad*,*azure*,*entra*] classification:[malicious, suspicious]
```

Samples that carry Microsoft identity endpoints, such as the OAuth token endpoint:

```
uri:["*login.microsoftonline.com*","*graph.microsoft.com*"] classification:[malicious, suspicious]
```

Config-extracted C2 on Microsoft cloud services:

```
uri-config:[*login.microsoftonline.com*,*graph.microsoft.com*,*azurewebsites.net*,*blob.core.windows.net*]
```

ATT&CK mapping:

```
attack-technique:[T1078, T1550, T1110]
```
