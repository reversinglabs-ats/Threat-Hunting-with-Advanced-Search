# 4.1  LDAP, Active Directory and Group Policy
*Part 4: Identity, Directory and Email*

## LDAP

### Spectra Analyze Advanced Search

LDAPNightmare is a pair of Windows LDAP flaws. CVE-2024-49113 crashes LSASS with a malicious referral response. CVE-2024-49112 is an LDAP RCE. Search for samples and exploits that target them:

```
exploit:[CVE-2024-49112, CVE-2024-49113]
```

Samples with LDAP URIs, which can be used for enumeration or Log4Shell-style callbacks:

```
uri:"ldap://*" classification:[malicious, suspicious]
uri-dynamic:"ldap://*" classification:[malicious, suspicious]
```

Binaries that use the Windows LDAP API:

```
pe-import:wldap32.dll classification:[malicious, suspicious]
```

LDAP enumeration tools by name:

```
filename:[*ldapsearch*,*adfind*,*ldapdomaindump*,*bloodhound*,*sharphound*] classification:[malicious, suspicious]
```

## Group Policy enumeration

Discovery tooling by name:

```
filename:[*powerview*,*sharphound*,*sharpgpo*,*grouper*,*adfind*,*pingcastle*,*bloodhound*] classification:[malicious, suspicious]
```

Original and compile-time names, to catch renamed copies:

```
pe-original-name:[SharpHound.exe,AdFind.exe,PingCastle.exe,Grouper2.exe] NOT filename:[SharpHound*,AdFind*,PingCastle*,Grouper2*]
```

PowerShell tooling in this area:

```
threatname:Script-PowerShell.* classification:[malicious, suspicious] filename:[*powerview*,*gpo*,*recon*]
```

Samples that map to the technique:

```
attack-technique:T1615
```

Wider Active Directory discovery:

```
attack-technique:[T1087, T1069, T1482, T1615]
```

Samples with LDAP strings:

```
uri-static:"ldap://*" classification:[malicious, suspicious]
```

Compiled enumerators with directory APIs:

```
pe-function:[ldap_search*,ldap_bind*,DsGetDcName*,NetGroupEnum*] classification:[malicious, suspicious]
```
