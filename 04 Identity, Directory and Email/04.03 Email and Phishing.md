# 4.3  Email and Phishing
*Part 4: Identity, Directory and Email*

## Electronic Mail (Email)

### Sender, recipient and subject

```
email-from:*@suspect-domain.* classification:[malicious, suspicious]
email-to:*@mycompany.com classification:[malicious, suspicious]
```

Subject lines such as invoice, payment and statement:

```
email-subject:[*invoice*,*payment*,*statement*] classification:[malicious, suspicious]
```

### Sender address, anywhere in the message headers

```
email:*@suspect-domain.*
```

### Unusual X-headers (data hiding, tooling markers)

```
email-x-key:* email-x-value:* classification:[malicious, suspicious]
```

### T1114: Outlook archive files (.ost, .pst)

```
filename:[*.ost,*.pst] classification:[malicious, suspicious]
filename:[*.ost,*.pst] size:50MB+
```

### Large email-related files (replaces "size may indicate exfiltration")

```
type:Email/* size:10MB+
```

### Mail that arrived through the SMTP ingest path

```
upload-source:smtp classification:[malicious, suspicious]
```

### Fuzzy phishing domains

Analyze has no fuzzy match. List typo variants of your own domain by hand:

```
domain:[mycornpany.com,mycompany-login.*,my-company.*,mycompany.*.top] classification:[malicious, suspicious]
```

### ATT&CK mapping

```
attack-technique:[T1071, T1114]
```

### Emails

| **Hunt** | **Analyze query** |
|---|---|
| Emails from a mail server, 5+ AVs | `email-from:*@domain.* p:5+` |
| Suspicious emails with attachments | `email-subject:* p:5+` (no attachment flag) |
| Attachments using an exploit | `exploit:* upload-source:smtp` |

## Mail protocols

### Spectra Analyze Advanced Search

Malicious email items by sender, subject or recipient:

```
email-from:*@<domain> classification:[malicious, suspicious]
email-subject:"*invoice*" classification:malicious
email-to:* email-from:* classification:malicious
```

## Azure subscription email

The exact subject:

```
email-subject:"Your Azure Subscription is ready"
```

The three words together:

```
email-subject:*Azure*Subscription*ready*
```

Only mail that came in through the SMTP ingest path:

```
email-subject:"Your Azure Subscription is ready" upload-source:smtp
```

Spoofed look-alikes of the sender:

```
email-subject:*Azure*Subscription* classification:[malicious, suspicious]
```

## Tycoon2FA phishing domains

Domains from the list, in groups that keep each query under 1024 characters:

```
domain:[<domain_1>,<domain_2>,<domain_3>]
```

Add subdomains, because the kit uses randomized hosts under each domain:

```
domain:[<domain_1>,*.<domain_1>,<domain_2>,*.<domain_2>]
```

The same list against URIs inside phishing pages and documents:

```
uri:[*<domain_1>*,*<domain_2>*]
```

The kit by name. The family name is free text, so this is a guess to confirm:

```
threatname:*Tycoon*
```

Phishing mail that carries these links, from the email path:

```
upload-source:smtp threatname:*.Phishing.*
```

ATT&CK mapping:

```
attack-technique:T1566
```
