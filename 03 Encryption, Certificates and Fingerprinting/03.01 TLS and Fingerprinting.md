# 3.1  TLS and Fingerprinting
*Part 3: Encryption, Certificates and Fingerprinting*

## Transport Layer Security (TLS)

### Certificate to sample

```
cert-serial:<SERIAL>
```

### Certificate issuer

```
cert-issuer-name:COMODO classification:[malicious, suspicious]
```

### Certificate subject

```
cert-subject-name:Piriform
cert-subject-org:"microsoft corporation" classification:malicious
```

### Any of the certificate fields at once

The `certificate` group keyword covers issuer and subject name, org and unit:

```
certificate:*<keyword>* classification:[malicious, suspicious]
```

### Expired certificates

Replace the date with today's date:

```
signer-valid-to:[* TO 2026-11-18T00:00:00Z] classification:[malicious, suspicious]
```

### Certificate validity longer than 3 years

There is no arithmetic. Narrow by the valid-from window instead:

```
signer-valid-from:[* TO 2023-11-18T00:00:00Z] signer-valid-to:[2026-11-18T00:00:00Z TO *]
```

### Certificate country

```
certificate-country:[RU, CN] classification:malicious
```

### Packer signing via Taggant
```
taggant-name:themida
```
