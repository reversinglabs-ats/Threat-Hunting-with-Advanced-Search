## LOTS Project trusted sites

Sites from the CSV, in groups that keep each query under 1024 characters. Always keep the verdict filter, because these are trusted sites and unfiltered results would be everything:

```
domain:[<site_1>,<site_2>,<site_3>] classification:[malicious, suspicious]
```

As config-extracted C2, which is the strongest signal for a trusted site:

```
uri-config:[*<site_1>*,*<site_2>*,*<site_3>*]
```

As sandbox output:

```
uri-dynamic:[*<site_1>*,*<site_2>*] classification:[malicious, suspicious]
```

Examples from the services the project lists, for a first pass:

```
uri-config:[*pastebin.com*,*raw.githubusercontent.com*,*discord.com/api/webhooks*,*api.telegram.org*,*drive.google.com*,*dropbox.com*,*mega.nz*,*webhook.site*]
```

ATT&CK mapping:

```
attack-technique:[T1102, T1567, T1105]
```

## webhook.site channels

Samples that reference the service:

```
domain:[webhook.site,*.webhook.site]
uri:*webhook.site* classification:[malicious, suspicious]
```

By indicator source:

```
uri-static:*webhook.site/* classification:[malicious, suspicious]
uri-dynamic:*webhook.site/* classification:[malicious, suspicious]
uri-config:*webhook.site*
```

Scripts that use it:

```
threatname:[Script-PowerShell.*,Script-Python.*,Script-Shell.*,Script-BAT.*] uri:*webhook.site* classification:[malicious, suspicious]
```

A specific webhook ID you got from an alert. UUIDs contain hyphens only, so no quoting is needed beyond the path:

```
uri:"*webhook.site/<UUID>*"
```

Several IDs from an investigation, in one query:

```
uri:["*webhook.site/<UUID_1>*","*webhook.site/<UUID_2>*","*webhook.site/<UUID_3>*"]
```

Related webhook-style exfiltration channels:

```
uri:[*discord.com/api/webhooks*,*hooks.slack.com*,*api.telegram.org*] classification:[malicious, suspicious]
```

ATT&CK mapping:

```
attack-technique:[T1567, T1059]
```
