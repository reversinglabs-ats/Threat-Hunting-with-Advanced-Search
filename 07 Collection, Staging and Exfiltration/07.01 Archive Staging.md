# 7.1  Archive Staging
*Part 7: Collection, Staging and Exfiltration*

## Archive data and tools

Archive, compression and encryption tooling and files:

```
filename:[*.7z,*.rar,*.zip,*.gz,*.tar,*.cab] classification:[malicious, suspicious]
```

Archivers and crypto-API users:

```
pe-function:[CryptEncrypt*,CryptDecrypt*,CryptProtectData*] classification:[malicious, suspicious]
pe-import:crypt32.dll classification:[malicious, suspicious]
```

Archive tools by name:

```
filename:[7z*,winrar*,rar.exe,pkzip*] classification:[malicious, suspicious]
```

Large archives:

```
filename:[*.7z,*.rar,*.zip] size:20MB+
```

Archive contents count (local appliance only):

```
filecount:[50 TO *] filename:[*.7z,*.rar,*.zip]
```

ATT&CK mapping for archive collected data:

```
attack-technique:T1560
```

## Archive followed by external transfer

### Transfer tools by name (the Transfer set)

```
filename:[rclone*,curl.exe,wget.exe,winscp*,pscp*,scp.exe,sftp.exe,azcopy*,aws.exe] classification:[malicious, suspicious, unknown]
```

Renamed copies, matched on the compile-time name:

```
pe-original-name:[rclone.exe,curl.exe,wget.exe,winscp.exe,pscp.exe,azcopy.exe] NOT filename:[rclone*,curl.exe,wget.exe,winscp*,pscp*,azcopy*]
```

Hash lookup for copies you already found:

```
hashes:[<sha256_1>, <sha256_2>]
```

### Archive tools by name (the Archive set)

```
filename:[7z.exe,7za.exe,7zr.exe,rar.exe,winrar.exe,tar.exe,makecab.exe] classification:[malicious, suspicious, unknown]
pe-original-name:[7z.exe,7za.exe,rar.exe,winrar.exe,makecab.exe] NOT filename:[7z*,rar*,winrar*,makecab*]
```

### The archives themselves

```
filename:[*.zip,*.7z,*.rar,*.tar,*.gz,*.cab] classification:[malicious, suspicious]
filename:[*.zip,*.7z,*.rar] size:20MB+ classification:[suspicious, unknown]
```

### Samples that carry exfiltration endpoints

```
domain:[*mega.nz,*gofile.io,*transfer.sh,*pixeldrain.com,*anonfiles.*] classification:[malicious, suspicious]
```

### ATT&CK mapping

```
attack-technique:[T1560, T1074, T1048, T1567]
```

## Large archives

### Archives at or above the original threshold

```
size:100MiB+ filename:[*.zip,*.rar,*.7z,*.tar,*.gz]
```

Same threshold written in bytes:

```
size:104857600+ filename:[*.zip,*.rar,*.7z,*.tar,*.gz]
```

Only archives that are suspicious or not yet classified:

```
size:100MiB+ filename:[*.zip,*.rar,*.7z,*.tar,*.gz] classification:[suspicious, unknown, malicious]
```

Archives of any size that unpack to many files (local appliance only):

```
filecount:[100 TO *] filename:[*.zip,*.rar,*.7z,*.tar,*.gz]
```

A size band, for example 100 MiB up to 2 GiB:

```
size:[100MiB TO 2GiB] filename:[*.zip,*.rar,*.7z]
```

### ATT&CK mapping

```
attack-technique:[T1560, T1074]
```

## Archives staged in temporary folders

### Large archives (the original test)

```
size:50MB+ filename:[*.zip,*.7z,*.rar]
```

Only archives that are not known-good:

```
size:50MB+ filename:[*.zip,*.7z,*.rar] classification:[suspicious, unknown, malicious]
```

Size band:

```
size:[50MB TO 2GB] filename:[*.zip,*.7z,*.rar]
```

Recently seen:

```
size:50MB+ filename:[*.zip,*.7z,*.rar] firstseen:3d-
```

Archives that unpack to many files, which suggests bulk collection (local appliance only):

```
filecount:[50 TO *] filename:[*.zip,*.7z,*.rar]
```

### Creators named in the original (the tools themselves)

```
filename:[7z.exe,winrar.exe,rar.exe] classification:[malicious, suspicious, unknown]
```
