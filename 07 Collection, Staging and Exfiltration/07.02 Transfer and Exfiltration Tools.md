# 7.2  Transfer and Exfiltration Tools
*Part 7: Collection, Staging and Exfiltration*

## Transfer utilities

### Transfer tools by file name

```
filename:[curl.exe,wget.exe,rclone*,winscp*,pscp*,scp.exe,sftp.exe,azcopy*,aws.exe,gcloud*,ftp.exe] classification:[malicious, suspicious, unknown]
```

By compile-time name, which catches renamed copies without a hash list:

```
pe-original-name:[curl.exe,wget.exe,rclone.exe,winscp.exe,pscp.exe,azcopy.exe,aws.exe,ftp.exe] NOT filename:[curl.exe,wget.exe,rclone*,winscp*,pscp*,azcopy*,aws.exe,ftp.exe]
```

### Their destinations, carried by the sample

```
uri-dynamic:[*mega.nz*,*gofile.io*,*transfer.sh*,*pastebin.com*,*s3.amazonaws.com*,*storage.googleapis.com*] classification:[malicious, suspicious]
```

Public destinations that were extracted by dynamic analysis, for a sample you are already investigating:

```
ipv4-dynamic:* classification:malicious
```

### ATT&CK mapping

```
attack-technique:[T1048, T1567, T1071]
```

## Command-line exfiltration utilities

### The tools (the original FileName list)

```
filename:[curl.exe,wget.exe,rclone.exe,winscp.exe,winscp.com,pscp.exe,scp.exe,sftp.exe,azcopy.exe,aws.exe,gcloud.exe,ftp.exe,bitsadmin.exe] classification:[malicious, suspicious, unknown]
```

### Renamed binaries (the original ProcessVersionInfoOriginalFileName check)

```
pe-original-name:[rclone.exe,winscp.exe,winscp.com,azcopy.exe,curl.exe] NOT filename:[rclone.exe,winscp.exe,winscp.com,azcopy.exe,curl.exe]
```

Rclone in particular, which is routinely renamed:

```
pe-original-name:rclone.exe NOT filename:rclone.exe
```

### Destinations the sample carries

Cloud storage and object stores:

```
uri:[*s3.amazonaws.com*,*blob.core.windows.net*,*storage.googleapis.com*,*mega.nz*] classification:[malicious, suspicious]
```

### Configuration files for these tools

rclone and WinSCP store their targets in config files, which may be submitted as samples:

```
filename:[rclone.conf,winscp.ini] classification:[malicious, suspicious, unknown]
```

### ATT&CK mapping

```
attack-technique:[T1048, T1567, T1537, T1197]
```

## FileZilla

FileZilla as files, by name:

```
filename:[filezilla*,fzsftp*,fzputtygen*]
```

By version-info fields (company, product, description, original and internal file name):

```
pe-company-name:*FileZilla* OR pe-product-name:*FileZilla* OR pe-description:*FileZilla* OR pe-original-name:*FileZilla*
```

Not clean, or renamed:

```
pe-product-name:*FileZilla* classification:[malicious, suspicious]
```

Renamed copies:

```
pe-product-name:*FileZilla* NOT filename:*filezilla*
```

ATT&CK mapping:

```
attack-technique:[T1048, T1567]
```

WinSCP as files, by name:

```
pe-company-name:*WinSCP* OR pe-product-name:*WinSCP* OR pe-description:*WinSCP* OR pe-original-name:winscp.*
```


## Script-based uploads

### Scripts by platform and verdict

The naming standard has subplatforms for PowerShell, WScript, JS, BAT and more:

```
threatname:[Script-PowerShell.*,Script-WScript.*,Script-JS.*,Script-BAT.*] classification:[malicious, suspicious]
```

By file name:

```
filename:[*.ps1,*.psm1,*.vbs,*.vbe,*.wsf,*.js,*.hta] classification:[malicious, suspicious]
```

### Upload primitives inside .NET assemblies

```
dotnet-method-name:[UploadFile,UploadString,UploadData,UploadValues,PostAsync] classification:[malicious, suspicious]
dotnet-type-name:[*WebClient*,*FtpWebRequest*,*MultipartFormDataContent*] classification:[malicious, suspicious]
dotnet-assembly:[System.Net.Http*,System.Net.WebClient*] classification:[malicious, suspicious]
```

### Upload APIs in native binaries

```
pe-function:[InternetWriteFile,HttpSendRequest*,FtpPutFile*,WinHttpWriteData,WinHttpSendRequest] classification:[malicious, suspicious]
```

### Upload targets in scripts

```
uri-static:["ftp://*","*multipart/form-data*"] classification:[malicious, suspicious]
```

### ATT&CK mapping

```
attack-technique:[T1059, T1048, T1567, T1041]
```
