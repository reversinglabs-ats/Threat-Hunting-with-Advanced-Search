# 9.2  Server Side Request Forgery (SSRF)
*Part 9: Web Application and Server-Side Threats*

## Hunts

### Internal and metadata targets inside samples

```
uri-static:[*127.0.0.1*,*localhost*,*169.254.169.254*,*0.0.0.0*] classification:[malicious, suspicious]
```

### Non-HTTP URL schemes (gopher, dict, file, ldap, tftp, jar and others)

```
uri-static:["gopher://*","dict://*","file:///*","ldap://*","tftp://*","jar:*","netdoc:*","expect://*","ssh2://*"] classification:[malicious, suspicious]
```

### Obfuscated IP forms for 127.0.0.1

Octal, hex and dword forms of 127.0.0.1:

```
uri-static:[*0x7f000001*,*2130706433*,*017700000001*,*0177.00.00.01*,*127.1*] classification:[malicious, suspicious]
```

### Open-redirect style parameters that point at internal hosts

```
uri-static:[*vuln-function=http*,*url=http://127*,*redirect=http://127*] classification:[malicious, suspicious]
```

### DNS rebinding services

```
domain:[*rbndr.us*,*lock.cmpxchg8b.com*,*nip.io*,*xip.io*] classification:[malicious, suspicious]
```
