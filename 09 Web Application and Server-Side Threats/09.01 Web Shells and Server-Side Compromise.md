# 9.1  Web Shells and Server-Side Compromise
*Part 9: Web Application and Server-Side Threats*

## Web shells

By detection name:

```
threatname:[Script-PHP.Backdoor.*,Script-ASP.Backdoor.*,Script-CGI.Backdoor.*]
```

Other script platforms:

```
threatname:[Script-Perl.Backdoor.*,Script-Python.Backdoor.*,Script-Shell.Backdoor.*,Script-JS.Backdoor.*]
```

Web-server file extensions that are not clean:

```
filename:[*.php,*.asp,*.aspx,*.jsp,*.jspx,*.cgi] classification:[malicious, suspicious]
```

Name patterns that web shells commonly use. Treat these as leads, not proof:

```
filename:[*shell*,*cmd*,*c99*,*r57*,*b374k*,*wso*] classification:[malicious, suspicious]
```

Backdoors of any platform (ASP.NET compiled, for example):

```
threatname:*.Backdoor.* filename:[*.aspx,*.ashx,*.dll]
```

Shells that exploit a CVE:

```
exploit:* threatname:[Script-PHP.*,Script-ASP.*]
```

Embedded C2 URIs in a script:

```
uri-static:* threatname:[Script-PHP.*,Script-ASP.*] classification:malicious
```

ATT&CK mapping (Server Software Component: Web Shell):

```
attack-technique:T1505
```

## ARTEX - Database engine writing a server-side script file - web shell planting

Web shells by detection name:

```
threatname:[Script-PHP.Backdoor.*,Script-ASP.Backdoor.*,Script-CGI.Backdoor.*,ByteCode-JAVA.Backdoor.*] classification:[malicious, suspicious]
```

Server-side script files that are not clean:

```
filename:[*.jsp,*.jspx,*.php,*.phtml,*.asp,*.aspx,*.ashx,*.cfm] classification:[malicious, suspicious]
```

Same extensions, files with no verdict yet (the triage queue after collecting suspect files from a web root):

```
filename:[*.jsp,*.jspx,*.php,*.phtml,*.asp,*.aspx,*.ashx,*.cfm] classification:unknown firstseen:3d-
```

Small script files, which web shells usually are (a one-line shell can be under 1 KB):

```
filename:[*.jsp,*.jspx,*.php,*.phtml,*.aspx,*.ashx] size:5KB- classification:[unknown, suspicious, malicious]
```

Samples that map to the techniques:

```
attack-technique:[T1505, T1190]
```

Exploits of public-facing applications (set the CVE you are tracking):

```
exploit:<CVE-ID>
```

Java archives with shell behavior, since `ByteCode` includes `JAVA`:

```
threatname:ByteCode-JAVA.* classification:[malicious, suspicious]
```

## ARTEX - Web - DB server lineage spawning curl to pull scripts or beacon to webhook.site

### Fetched script payloads

Scripts that are not clean:

```
filename:[*.ps1,*.bat,*.cmd,*.vbs,*.py,*.sh] classification:[malicious, suspicious]
```

By detection name:

```
threatname:[Script-PowerShell.*,Script-BAT.*,Script-Python.*,Script-Shell.*,Script-WScript.*] classification:[malicious, suspicious]
```

Samples that point at script URLs:

```
uri:[*.ps1,*.bat,*.cmd,*.vbs,*.py,*.sh] classification:[malicious, suspicious]
```

Downloader scripts with a config-extracted or dynamic URL:

```
uri-dynamic:"http*://*" threatname:Script-Shell.* classification:[malicious, suspicious]
```

### The server-side foothold

Web shells:

threatname:[Script-PHP.Backdoor.*,Script-ASP.Backdoor.*,Script-CGI.Backdoor.*] classification:[malicious, suspicious]

## Exchange mailbox export and reconnaissance

### Web shells on IIS and Exchange

```
threatname:[Script-ASP.Backdoor.*,Script-PHP.Backdoor.*,ByteCode-MSIL.Backdoor.*] classification:[malicious, suspicious]
```

By file type and name:

```
filename:[*.aspx,*.ashx,*.asmx,*.asp] classification:[malicious, suspicious]
```

Compiled web shells (DLLs dropped in the IIS or Exchange directories):

```
threatname:ByteCode-MSIL.* filename:*.dll classification:[malicious, suspicious]
```

### Exchange exploits that drop web shells

ProxyLogon, ProxyNotShell and related. Confirm the CVE IDs against the advisories you track:

```
exploit:[CVE-2021-26855, CVE-2021-26857, CVE-2021-26858, CVE-2021-27065, CVE-2022-41040, CVE-2022-41082]
```

### Scripts that call Exchange cmdlets

Analyze does not search script bodies, so rely on the detection name and indicators of PowerShell scripts:

```
threatname:Script-PowerShell.* classification:[malicious, suspicious]
filename:[*.ps1,*.psm1] classification:[malicious, suspicious] av-detection:*exchange*
```

### Samples with Exchange-related endpoints

```
uri:[*/ecp/*,*/owa/*,*/autodiscover/*,*/powershell*] classification:[malicious, suspicious]
```

### Mailbox exfiltration artifacts

Outlook archives that were exported:

```
filename:[*.pst,*.ost] classification:[malicious, suspicious]
```

### ATT&CK mapping

```
attack-technique:[T1114, T1087, T1505, T1059]
```
