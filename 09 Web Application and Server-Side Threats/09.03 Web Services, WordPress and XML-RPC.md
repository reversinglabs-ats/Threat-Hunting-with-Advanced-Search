# 9.3  Web Services, WordPress and XML-RPC
*Part 9: Web Application and Server-Side Threats*

## Web services

ATT&CK mapping for the web service technique:

```
attack-technique:T1102
```

Samples that use public web services for C2:

```
uri-config:[*pastebin.com*,*github.com*,*raw.githubusercontent.com*,*docs.google.com*,*dropbox.com*,*telegram.org*] classification:[malicious, suspicious]
```

Samples referencing WordPress admin paths:

```
uri:[*wp-admin*,*wp-login.php*,*xmlrpc.php*] classification:[malicious, suspicious]
```

PHP samples that are not clean:

```
threatname:Script-PHP.* classification:[malicious, suspicious]
```

## XML-RPC

WordPress XML-RPC endpoint references (commonly abused for brute force and pingback abuse):

```
uri:*xmlrpc.php* classification:[malicious, suspicious]
```

Other XML-RPC endpoints:

```
uri:[*/xmlrpc*,*/RPC2*] classification:[malicious, suspicious]
```

Web shells and scripts that call it:

```
threatname:[Script-PHP.*,Script-Python.*] uri-static:*xmlrpc* classification:[malicious, suspicious]
```

RPC API use in binaries:

```
pe-function:[RpcBindingFromStringBinding*,RpcStringBindingCompose*,NdrClientCall*] classification:[malicious, suspicious]
```
