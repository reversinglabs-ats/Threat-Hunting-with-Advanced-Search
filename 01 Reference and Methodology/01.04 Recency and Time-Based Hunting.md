# 1.4  Recency and Time-Based Hunting
*Part 1: Reference and Methodology*

## Hunts

New today and already known to be bad:

```
firstseen:1d- classification:malicious
```

A malware type over the last week:

```
threatname:*.Ransomware.* firstseen:1w-
```

Old files that are still active:

```
lastseen:1d- firstseen:1y+
```

Recently re-analyzed files with a bad verdict:

```
lastanalysis:1d- classification:[malicious, suspicious]
```

A fixed date range:

```
firstseen:[2026-11-01T00:00:00Z TO 2026-11-07T23:59:59Z] classification:malicious
```

Old compile time but a new sighting, which can mean a repackaged or backdated build:

```
pe-timestamp:[* TO 2015-01-01T00:00:00Z] firstseen:1w-
```

Repeat sightings and first-time sightings:

```
submissions:[10 TO *] classification:malicious
submissions:1 firstseen:1d-
```

New certificates on recently seen files:

```
signer-valid-from:[2026-11-01T00:00:00Z TO *] firstseen:7d-
```

Files whose verdict changed recently:

```
classification:suspicious lastanalysis:1d-
```
