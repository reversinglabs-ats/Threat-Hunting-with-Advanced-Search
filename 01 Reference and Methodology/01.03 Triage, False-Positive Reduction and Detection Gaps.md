# 1.3  Triage, False-Positive Reduction and Detection Gaps
*Part 1: Reference and Methodology*

## Triage and false-positive reduction

Remove files that are known good:

```
NOT classification:known
```

Only files that still need a decision:

```
classification:[unknown, suspicious]
```

Identify known software, then exclude it from a hunt:

```
appid-product-name:<product>
appid-company-name:"<vendor>"
appid-product-type:<type>
appid-description:"*<text>*"
classification:unknown NOT appid-product-name:<product>
```

Exclude files signed by a trusted publisher:

```
filename:[*.exe,*.dll] classification:unknown NOT cert-subject-org:"microsoft corporation"
```

Exclude libraries from a trusted vendor:

```
classification:[unknown, suspicious] NOT third-party-publisher:"<vendor>"
```

Only files that can be downloaded from the cloud:

```
available:true
```

A combined triage query:

```
classification:unknown available:true firstseen:1d- NOT cert-subject-org:"microsoft corporation"
```

## Detection gaps and AV disagreement

Reversing Labs says malicious, but few engines detect it:

```
classification:malicious p:[* TO 3]
```

Suspicious with low engine coverage:

```
classification:suspicious av-count:[* TO 2]
```

Many engines detect it, but it is not classified as malicious (a possible false positive or a classification lag):

```
p:10+ NOT classification:malicious
```

Engine threat level 8 to 10:

```
av-threatlevel:[8, 9, 10]
```

Detected by one vendor and few others. Replace <vendor> with the vendor name shown in the autocomplete:

```
av-<vendor>:* p:[* TO 2]
```

A specific detection string that Reversing Labs has not classified:

```
av-detection:*<string>* classification:unknown
```

New samples that no engine detects yet:

```
firstseen:1d- p:0
```

High Reversing Labs threat level against a low engine count:

```
threatlevel:[4 TO *] p:[* TO 5]
```

High risk score against a low engine count:

```
riskscore:8+ p:[* TO 3]
```
