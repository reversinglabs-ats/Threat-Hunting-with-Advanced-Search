# 1.5  Submitters and Ingest Sources
*Part 1: Reference and Methodology*

## Hunts

Files submitted by specific users:

```
submission-user:[admin, analyst]
```

Files submitted by a user and judged bad:

```
submission-user:<username> classification:[malicious, suspicious]
```

Submissions in a time window:

```
submission-time:[2024-01-01T00:00:00Z TO 2024-06-01T00:00:00Z] classification:malicious
```

Analyst-tagged samples:

```
tag-user:[malware, clean]
```

Samples by ingest source, such as email gateways or APIs:

```
upload-source:[smtp, api, s3, fileshare]
```

Samples from a custom source tag:

```
upload-source-tag:myapp*
```

Files submitted more than once (repeat exposure):

```
submissions:[3 TO *]
```
