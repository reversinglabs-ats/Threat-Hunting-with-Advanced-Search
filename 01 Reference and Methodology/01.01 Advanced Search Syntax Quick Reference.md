# 1.1  Advanced Search Syntax Quick Reference
*Part 1: Reference and Methodology*

## Syntax cheat sheet

| **Need** | **Syntax** | **Example** |
|---|---|---|
| Keyword and value | `keyword:value` | `classification:malicious` |
| AND (default), OR, NOT | `AND` `OR` `NOT` (case-insensitive) | `av-detection:*linux* NOT classification:[malicious, suspicious]` |
| Any of a list | `keyword:[a,b,c]` | `classification:[suspicious, unknown]` |
| Range | `keyword:[a TO b]`, with `*` as an open end | `size:[50000 TO 70000]` |
| Wildcards | `*` for any run of characters, `?` for one character | `av-detection:emo?et` |
| Spaces or special characters `[ ] ( ) :` | double quotes | `cert-subject-org:"microsoft corporation"` |
| Numeric and date modifiers | trailing `+` or `-` | `riskscore:8+`, `firstseen:1w-` |
| Grouping | parentheses | `(av-detection:trojan OR av-detection:wannacry)` |
