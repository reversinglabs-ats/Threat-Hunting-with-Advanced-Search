# 2.1  DNS, Encrypted DNS and Domain Impersonation
*Part 2: Network Protocols and Infrastructure*

## Domain Name System

### Suspicious or uncommon TLDs

Suspicious or uncommon TLDs, as one list with wildcards (a query is limited to 1024 characters, so split the list if you extend it):

```
domain:[*.ru,*.su,*.cn,*.tk,*.top,*.xyz,*.biz,*.info,*.buzz,*.cf,*.ga,*.gq,*.onion,*.bit,*.zil,*.eth,*.xxx,*.cam,*.cash,*.casino] classification:[malicious, suspicious]
```

Same TLDs, URIs extracted by static analysis:

```
uri-static:[*.ru/*,*.su/*,*.tk/*,*.top/*,*.xyz/*] classification:[malicious, suspicious]
```

### Dynamic DNS providers

```
domain:[*.duckdns.org,*.no-ip.org,*.no-ip.biz,*.ddns.net,*.dyndns.org,*.hopto.org,*.zapto.org] classification:[malicious, suspicious]
```

### Public IP lookup services

Public IP lookup services such as myip, ipinfo, ipchicken and portquiz, which malware often calls first to learn its external address:

```
domain:[*myip.*,*ipinfo.*,*ipchicken.*,*ipaddr.*,*meineip.*,*meuip.*,*portquiz.*,*portchecktool.*,*ipid.*,*iptools.*,*hostip.*,*canyouseeme.*] classification:[malicious, suspicious]
```

### Base64-looking queries

Base64-looking content (a double equals sign before a dot) in URIs and domains extracted by static and dynamic analysis:

```
uri:"*==.*" classification:[malicious, suspicious]
```

### C2 beacon-style paths

C2 beacon-style paths such as .getid, .gettask and .getupdates:

```
uri-dynamic:[*getid*,*gettask*,*getupdates*]
```

### Pivot on one domain, IP or URL

A bare value works as a non-keyword IOC search:

```
"<SUSPECT_DOMAIN>"
```

### Domains in a TLD

| **Hunt** | **Analyze query** |
|---|---|
| Domains in a TLD | `domain:*.xyz classification:[malicious, suspicious]` |

## Encrypted DNS (DoH and DoT)

### Samples that reference known DoH resolver domains

```
domain:[cloudflare-dns.com,dns.google,dns.google.com,dns.quad9.net,dns9.quad9.net,dns10.quad9.net,security-filter-dns.cleanbrowsing.org,family-filter-dns.cleanbrowsing.org,adult-filter-dns.cleanbrowsing.org,dns.adguard.com,dns-family.adguard.com,dot.xfinity.com,mozilla.cloudflare-dns.com] classification:[malicious, suspicious]
```

### Same list as URIs

```
uri:["https://cloudflare-dns.com/*","https://dns.google/*","https://dns.quad9.net/*","https://dns.adguard.com/*"] classification:[malicious, suspicious]
```

The DoH endpoint path is `/dns-query`. Add `*dns-query*` to narrow results:

```
uri:*dns-query* classification:[malicious, suspicious]
```

### Samples that contact public DoH resolver IPs (Quad9, Google, Cloudflare)

```
ipv4:[9.9.9.9,9.9.9.10,149.112.112.112,149.112.112.9,149.112.112.10,8.8.8.8,8.8.4.4,1.1.1.1,1.0.0.1,104.16.249.249,104.16.248.249] classification:[malicious, suspicious]
ipv6:["2620:fe::fe","2620:fe::9","2001:4860:4860::8888","2001:4860:4860::8844","2606:4700:4700::1111","2606:4700:4700::1001"] classification:[malicious, suspicious]
```

### DNS-over-TLS port

```
uri:"*:853*" classification:[malicious, suspicious]
```

## PowerShell commands in DNS responses

The named domain:

```
domain:[tohknet.com,*.tohknet.com]
```

Same, as a URI or config indicator:

```
uri:*tohknet.com* OR uri-config:*tohknet.com*
```

Samples that query a TXT record for a command (a PowerShell downloader that uses DNS as the channel):

```
threatname:Script-PowerShell.* uri-dynamic:* classification:[malicious, suspicious]
```

PowerShell scripts that use DNS lookups:

```
threatname:Script-PowerShell.* av-detection:*dns* classification:[malicious, suspicious]
```

ATT&CK mapping:

```
attack-technique:[T1059, T1071]
```

## Typosquatting

Variants of your own domain, as a list with wildcards:

```
domain:[mycornpany.com,rnycompany.com,mycompany-login.*,my-company.*,mycompany.*.top] classification:[malicious, suspicious]
```

Same list as URIs found in files:

```
uri-static:[*mycornpany.com*,*rnycompany.com*,*mycompany-login.*] classification:[malicious, suspicious]
```

Brand name inside any suspicious domain:

```
domain:*mycompany* classification:[malicious, suspicious]
```

Brand name inside config-extracted C2:

```
uri-config:*mycompany* classification:malicious
```

Phishing detection names:

```
threatname:*.Phishing.*
```

### Anti-phishing and brand monitoring

| **Hunt** | **Analyze query** |
|---|---|
| Domains similar to a legitimate one | `domain:*company*` plus a hand-built variant list, for example `domain:[compan1.com,cornpany.com]` |
| Phishing page text, titles | Not possible. Use `threatname:*.Phishing.*` |
