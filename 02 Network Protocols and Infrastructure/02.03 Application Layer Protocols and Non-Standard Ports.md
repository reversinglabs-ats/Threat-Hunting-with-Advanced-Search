# 2.3  Application Layer Protocols and Non-Standard Ports
*Part 2: Network Protocols and Infrastructure*

## Application Layer Protocol

### Analyze hunts

Samples mapped to the technique and its protocol sub-techniques:

```
attack-technique:T1071
```

Samples that contact web, file, mail or DNS endpoints in dynamic analysis:

```
uri-dynamic:[http*,ftp*,smtp*] classification:[malicious, suspicious]
```

## Non-Standard Port

### Analyze approach

Endpoints in URIs with unusual ports:

```
uri:[*:8088*,*:4443*,*:8443*,*:5938*] classification:[malicious, suspicious]
```

Malware-config C2 URIs with an explicit port:

```
uri-config:"*:*" classification:malicious
```

ATT&CK mapping for this technique:

```
attack-technique:T1571
```
