# 2.2  Internet Protocol Address (IPv4)
*Part 2: Network Protocols and Infrastructure*

## Hunts

### Search a CIDR (replaces INCIDR)

Analyze has no CIDR operator. Convert the range to wildcards. For `10.148.0.0/24`:

```
ipv4:10.148.0.*
```

For a /16, such as `10.148.0.0/16`:

```
ipv4:10.148.*
```

For a handful of ranges:

```
ipv4:[10.148.0.*, 10.149.0.*, 192.168.5.*]
```

### Hunt in a CIDR for bad files only

```
ipv4:10.148.0.* classification:[malicious, suspicious]
```

### Static versus dynamic

```
ipv4-dynamic:10.148.0.* NOT ipv4-static:10.148.0.*
```

### Single IP, non-keyword

```
198.51.100.25
```

### IPv6

```
ipv6:"2001:db8*"
```

### Files that contain a raw IP in a URL, not a domain

URIs with an IP-looking host (a wildcard approximation that only matches dotted quads):

```
uri-static:"http://*.*.*.*/*" classification:[malicious, suspicious]
```

## Subnets and malware contacting an IP

| **Hunt** | **Analyze query** |
|---|---|
| Subnet | `ipv4:10.0.0.*` (wildcard in place of CIDR) |

| **Hunt** | **Analyze query** |
|---|---|
| Malware contacting an IP or subnet | `ipv4-dynamic:194.36.189.179` |

## Reputation lookups for an IP, URL or domain

### Is this IP, URL or domain tied to bad files?

Bare IOC values work without a keyword. IPs and emails accept wildcards.

```
"198.51.100.25" class:malicious
"http://www.evildomain.com/gate.php?13,35869"
198.51.100.* AND NOT class:goodware
```

### Same lookups with explicit keywords

```
ipv4:198.51.100.25 classification:[malicious, suspicious]
uri:"http://www.evildomain.com/*" classification:malicious
```

### High-confidence-only filter

```
ipv4:198.51.100.25 threatlevel:[3 TO *] riskscore:7+
```
