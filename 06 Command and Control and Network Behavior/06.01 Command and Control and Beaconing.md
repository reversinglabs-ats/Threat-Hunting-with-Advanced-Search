# 6.1  Command and Control and Beaconing
*Part 6: Command and Control and Network Behavior*

## Beaconing

Malware samples with C2 addresses extracted from their config:

```
classification:malicious uri-config:*
```

C2 hosts that match dynamic-DNS providers:

```
classification:[malicious, suspicious] uri-config:[*duckdns.org, *no-ip.*, *ddns.net, *dyndns.*]
```

Samples that talk to one specific suspect IP or domain (static or dynamic analysis):

```
ipv4:"<SUSPECT_IP>" OR domain:"<SUSPECT_DOMAIN>"
```

Samples with a known malware-config mutex, which often marks a persistent implant:

```
mutex-config:*
```

C2 addresses seen only through dynamic analysis, in unclassified samples:

```
uri-dynamic:* classification:unknown
```

Samples that exploit a CVE and also have config-extracted C2:

```
exploit:* uri-config:*
```

Non-keyword IOC lookup (IPs, domains, URLs, hashes and emails work without a keyword):

```
"<SUSPECT_IP>" "<SUSPECT_DOMAIN>" class:malicious
```

## Outbound command-and-control activity

Rare or unknown samples that contact the network in dynamic analysis. This is the closest match to the "rare process" idea:

```
ipv4-dynamic:* classification:unknown
uri-dynamic:* classification:unknown firstseen:7d-
```

Samples that were only recently seen. A newly seen file that talks to the network is the file-side version of a rare process:

```
firstseen:3d- classification:[unknown, suspicious] uri-dynamic:*
```

Pivot on an indicator your EDR gave you:

```
ipv4:"<REMOTE_IP>" OR domain:"<REMOTE_DOMAIN>"
```

Non-standard web ports in the sample's URIs (T1571):

```
uri:["*:8080*","*:8443*","*:8000*","*:8888*","*:9000*"] classification:[malicious, suspicious]
```

Sample name of a process your EDR flagged, as a file hunt:

```
filename:<process_name>.exe classification:[unknown, suspicious, malicious]
```

Same name, compile-time name:

```
pe-original-name:<process_name>.exe
```

ATT&CK mapping:

```
attack-technique:[T1071, T1571]
```

### Behavior (sandbox detonation)

| **Hunt** | **Analyze query** |
|---|---|
| Network output containing a string, PE | `uri-dynamic:*bumblebee* type:PE/*` |
| Samples contacting an endpoint | `uri-dynamic:*vpnchecker.php*` |
| PowerShell with execution-policy bypass | Not possible. Closest: `type:Text/* av-detection:*powershell*` |
| Dynamic mutexes | `mutex-dynamic:<name>` |

### Suspicious endpoints and hardcoded addresses

| **Hunt** | **Analyze query** |
|---|---|
| URLs with a suspicious endpoint | `uri:*logpost.php* classification:[malicious, suspicious]` |

| **Hunt** | **Analyze query** |
|---|---|
| Hardcoded malicious address | `domain:maliciousdomain.com OR uri-static:*maliciousdomain.com*` |

### Malware from a URL

| **Hunt** | **Analyze query** |
|---|---|
| Malware from a URL | `itw:cdn.domain.com p:5+` |

### Threat categories

| **Category** | **Analyze query** |
|---|---|
| Malware | `classification:malicious` |
| Botnet Command and Control Server | `uri-config:* classification:malicious` |
| Phishing | `threatname:*.Phishing.*` |
| Cryptocurrency Mining | `threatname:*.Coinminer.*` |

## High-frequency HTTP and HTTPS connections

### Pivot on a destination returned by the hunt

```
ipv4:"<REMOTE_IP>" OR domain:"<REMOTE_URL_HOST>"
```

Bare IOC form:

```
"<REMOTE_IP>" class:malicious
```

URL with path:

```
uri:"<REMOTE_URL>*" classification:[malicious, suspicious]
```

### Samples that carry web C2 or download URLs

```
uri-config:* classification:malicious
uri-dynamic:"http*://*" classification:[malicious, suspicious] firstseen:7d-
```

### The LOLBin and download tools as files (renamed copies)

```
pe-original-name:[certutil.exe,bitsadmin.exe,curl.exe,wget.exe] NOT filename:[certutil.exe,bitsadmin.exe,curl.exe,wget.exe]
```

### ATT&CK mapping

```
attack-technique:[T1071, T1105]
```
