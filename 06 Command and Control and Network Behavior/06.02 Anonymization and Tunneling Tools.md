# 6.2  Anonymization and Tunneling Tools
*Part 6: Command and Control and Network Behavior*

## Tor

### Tor proxy and gateway domains

```
domain:[t2w.pw,onion.cab,onion.casa,onion.city,onion.direct,onion.dog,onion.ink,onion.it,onion.link,onion.lt,onion.lu,onion.nu,onion.pet,onion.plus,onion.rip,onion.sh,onion.to,onion.top,tor2web.*,torlink.co,hiddenservice.net,*.tor-gateways.de]
```

### Same list as URIs found by static analysis

```
uri-static:[*onion.to*,*onion.link*,*tor2web.*,*torlink.co*,*hiddenservice.net*,*tor-gateways.de*]
```

### Only malicious or suspicious samples

```
domain:[*.onion,onion.to,onion.link,onion.top,tor2web.*,torlink.co] classification:[malicious, suspicious]
```

### Onion addresses in malware config or sandbox output

```
uri-config:*.onion* OR uri-dynamic:*.onion*
```

### Tor client binaries

```
filename:[tor.exe,tor-browser*,torbrowser*,obfs4proxy*] classification:[malicious, suspicious]
```

### Tor ports embedded in URIs

```
uri:["*:9001*","*:9030*"] classification:[malicious, suspicious]
```

## ngrok

By file name:

```
filename:ngrok*
```

By version-info fields, which catches renamed copies:

```
pe-product-name:*ngrok* OR pe-description:*ngrok* OR pe-original-name:ngrok.exe
```

Renamed copies only:

```
pe-product-name:*ngrok* NOT filename:ngrok*
```

Tunnel endpoints inside a sample:

```
domain:[*.ngrok.io,*.ngrok-free.app,*.ngrok.app,*.ngrok.com] classification:[malicious, suspicious]
```

As configuration or sandbox output:

```
uri-config:*ngrok* OR uri-dynamic:*ngrok*
```

ATT&CK mapping:

```
attack-technique:[T1572, T1090]
```

## SSH reverse tunnels

SSH clients as files:

```
filename:[ssh.exe,plink*,putty*,dropbear*] classification:[malicious, suspicious, unknown]
```

PuTTY-family tools by version info:

```
pe-product-name:*PuTTY* classification:[malicious, suspicious, unknown]
```

Renamed copies:

```
pe-original-name:[ssh.exe,plink.exe] NOT filename:[ssh.exe,plink*]
```

ATT&CK mapping:

```
attack-technique:[T1572, T1021]
```

## Cloudflared

By file name (the binary has no metadata to match instead):

```
filename:*cloudflared*
```

Not clean:

```
filename:*cloudflared* classification:[malicious, suspicious, unknown]
```

Cloudflare tunnel endpoints inside a sample:

```
domain:[*.trycloudflare.com,*.cfargotunnel.com] classification:[malicious, suspicious]
```

As configuration or sandbox output:

```
uri-config:*trycloudflare.com* OR uri-dynamic:*trycloudflare.com*
```
